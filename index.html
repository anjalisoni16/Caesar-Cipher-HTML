02 / SECURITY ANALYSIS

Why Caesar Cipher is weak

01

Only 26 possible keys

An attacker can test every possible shift extremely quickly. This is called a brute-force attack.

02

Preserves letter patterns

The cipher does not hide frequency patterns, making the underlying language easier to recognize.

03

Not modern encryption

Caesar Cipher is useful for learning cryptography concepts, but it provides no meaningful modern confidentiality.
